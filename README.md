A life simulation game named Whiplash where players guide a trumpet-playing character through career and life choices, balancing stats to achieve success. Developed in pure Java as an Object-Oriented Programming (OOP) academic project.

## About the Game

Whiplash challenges players to:

- Make strategic life decisions affecting multiple character stats
- Balance health, mood, skills, and finances
- Achieve a minimum score threshold to win
- Experience consequences of choices through a dynamic stat system
- Guide a musician protagonist through career challenges


## Technologies

- Core: Java 11 (Pure OOP implementation)
- Architecture: MVC pattern with robust class hierarchy


## Game Systems:

- Stat tracking (health, mood, skill, money)
- Career progression
- Inventory management
- Choice-based narrative


## Gameplay Features

- Stat Management: Balance health, mood, skill, and finances
- Career Progression: Choose formal/informal career paths
- Cultural Choices: Collect vinyls and wines that affect stats
